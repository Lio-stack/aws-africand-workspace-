# AfriCand Work Space (AWS) — Vision Produit

## 1. Positionnement
AfriCand Work Space (AWS) est une plateforme B2B privée opérée par AfriCand Consulting.
Elle met en relation des entreprises validées avec des consultants indépendants seniors préalablement qualifiés.

Ce n'est pas un annuaire public. C'est un outil métier contrôlé, confidentiel, premium.

## 2. Problèmes résolus
- Entreprises : difficulté à trouver des seniors vérifiés, disponibles, adaptés au besoin.
- Consultants : besoin d'opportunités qualifiées sans exposition publique.
- AfriCand : besoin d'un système central pour qualifier, matcher, proposer, contractualiser, suivre.

## 3. Les trois espaces
| Espace | Utilisateurs | Finalité |
|---|---|---|
| AWS Experts | Consultants candidats / qualifiés | Candidature, profil, disponibilités, missions, livrables, paiements autorisés |
| AWS Business | Entreprises validées + membres | Exprimer besoin, explorer profils anonymisés autorisés, shortlists, introductions, suivi missions |
| AWS Administration | Équipe AfriCand | Validation, qualification, matching, propositions, contrats, facturation, pilotage |

## 4. Principes produit
1. Confidentialité par défaut : identité réelle ≠ profil anonymisé.
2. Contrôle humain : AfriCand décide. Pas d'attribution automatique.
3. Matching explicable : score pondéré + justification lisible.
4. Moindre privilège : chaque rôle ne voit que le nécessaire.
5. Traçabilité : toute opération sensible est journalisée.
6. Premium et sobre : image internationale, fiable.

## 5. Parcours clés (MVP)
1. Consultant : candidature → validation AfriCand → profil qualifié → opportunité → réponse → mission → livrables.
2. Entreprise : inscription → validation AfriCand → besoin → exploration anonymisée → shortlist → demande introduction → proposition → mission.
3. Admin : valider → qualifier → matcher → comparer → introduire → proposer → contractualiser → suivre → facturer.

## 6. Non-objectifs (MVP)
- Pas de messagerie libre directe entreprise ↔ consultant sans médiation.
- Pas de paiement automatique / escrow.
- Pas d'IA autonome de décision.
- Pas de marketplace publique.
- Pas de microservices.

## 7. Indicateurs de succès
- Délai qualification consultant / entreprise.
- Taux besoin → shortlist → introduction → proposition → mission.
- Qualité matching (taux d'acceptation admin).
- Zéro fuite inter-entreprise / inter-consultant.
- Exhaustivité audit sur opérations sensibles.
